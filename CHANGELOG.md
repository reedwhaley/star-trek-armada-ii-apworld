# Changelog

## 0.1.0

Initial public release of the Star Trek: Armada II Archipelago integration.

### Highlights

- Custom Archipelago client with a built-in Mission Launcher.
- Individual mission-access progression across Federation, Klingon, and Borg campaigns.
- 302 locations: mission completion, objective transitions, and mission-tech-aware first builds.
- Player-only permanent upgrades, helpful items, and reversible traps.
- Durable check and received-item ledgers, native campaign-selector launch routing, and final-goal reporting through Borg Mission 10: Rifts.

### Installation

Copy `armada2_observer.dll` and `armada2_injector.exe` beside `Armada2.exe`, install
`star_trek_armada_ii.apworld` through Archipelago custom worlds, restart the Launcher,
and select the Armada II install folder when the client first starts.

The client does not replace stock game files. It temporarily disables only application
startup videos for managed launches and restores them when the launched game process exits.
